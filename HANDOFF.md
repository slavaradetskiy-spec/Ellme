### PDF-экспорт (только на staging, НЕ на prod)
Последний коммит на staging: `a90b538`. Кнопка скачивания на экране Аналитика — тёмно-зелёный блок под селектором периода.

**Структура PDF:**
- **Страница 1 (Профиль):** большой серифный «Отчёт» 44px + диапазон дат жирным, линия, аватар+имя, таблица (email/телефон/возраст/пол/рост/вес/норма воды), «Запрос»
- **Страницы дневника:** по N дней на страницу (жадная упаковка до 9 meal'ов на лист = 3 дня × 3 meal'а). Заголовок «Дневник питания · 09.04.2026 – 15.04.2026» **только на 1-й diary-странице**
- **Последняя страница:** Аналитика — 9 тайлов 2-в-ряд, с графиками 85px высоты, осями, подписями значений на точках, цветами метрик

**Meal-тайл (3 колонки/день):**
- Фото 180×180 square, pre-baked через canvas coverToDataURL (cover или collage если несколько фото)
- Умный коллаж по ориентации: 2 landscape → top/bottom, 2 portrait → side-by-side, 3 → layouts по ориентации, 4+ → 2×2
- Снизу: тип + время, описание (1 line clamp, 90 chars max), `Голод: X · После: Y` на одной строке
- Tile height ~230px

**Футер-колонтитул (на КАЖДОЙ странице):**
- Слева: зелёный круг `ELL·ME` + тэглайн «Eat healthier / Listen to your body / Live longer» (E/L/L зелёные)
- Справа: `ellme.ru` 22px серифом + «Пространство осознанного / отношения к себе» на 2 строках

**Геометрия страницы (единая):**
- Top pad 48, side pad 56, **bottom pad 124** (= 22 footer offset + 54 logo + 48 breathing = симметрично top)
- Content box: 794 × 951 px
- MAX_BODY для дневника: 917 (951 − 34 под заголовок 1-й стр.)
- Dayheight estimate: 24 + rows × 230 + (rows-1) × 10 + 14 margin

**Техника:**
- jsPDF + html2canvas подгружаются через dynamic `import()`
- Каждая страница рендерится в СВОЁМ off-screen host (position:fixed; left:-20000px) и снимается html2canvas с явными `width: 794, height: 1123, windowWidth/Height` — предотвращает bleed между siblings
- Все фото pre-cached в photoCache как same-origin data:image/jpeg через canvas (убивает CORS-гонки и сплющивание object-fit)

## Баг-хистори, важно помнить:
- HTML `<div/>` — **НЕ самозакрывающийся**, браузер парсит как `<div>`, всё последующее вкладывается внутрь. Всегда писать `<div></div>` явно.
- html2canvas игнорирует `object-fit:cover` на `<img>` — рендерит как `fill` (сплющивает). Фиксится через canvas pre-bake в data: URI.
- iOS Safari `<input type="date">` имеет intrinsic min-width, игнорит `width:100%` + `boxSizing:border-box`. Лечится `WebkitAppearance:'none'` + `appearance:'none'`.
- Vercel Toolbar на staging-домене может накрывать нижний таб-бар на iPhone. Для отключения — Vercel Dashboard → Project → Settings → Toolbar → Off (доступ только у юзера).
- Инструмент Serif не грузится в PDF-контексте — фолбек на Georgia. Georgia `font-weight:700` = жирный, так что всегда выставлять `font-weight:400` явно для значений, чтобы не было жирного.
